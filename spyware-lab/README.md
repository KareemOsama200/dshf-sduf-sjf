# Spyware Lab — مشروع تخرج (بيئة معزولة)

تطبيق Collector (أندرويد) + سيرفر استقبال (Flask) + أداة كشف (adb).
مخصص للتجربة على emulator أو تليفون تجربة عليه بيانات وهمية فقط.

## بنية المشروع
- collector/  -> تطبيق أندرويد (Kotlin)
- server/     -> سيرفر Flask + dashboard
- detection/  -> audit.py كشف الأذونات الخطيرة
